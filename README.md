# NIGHTSHIFT bot v3 — бот + веб-панель

## Запуск
1. Распакуй файлы поверх своей папки NIGHTSHIFT. Твой `.env` оставь, но **добавь в него строку**:
   `PANEL_PASSWORD=придумай-длинный-пароль`
2. Установи новые библиотеки: `python3 -m pip install -r requirements.txt`
3. Запусти: `python3 bot.py`
4. Открой в браузере: **http://127.0.0.1:8000** и войди с паролем.

Бот и панель запускаются одной командой и работают, пока открыт терминал.
Только панель, без бота: `python3 run_panel.py`.

## Что умеет панель
- **Обзор** — новые заказы, непрочитанные диалоги, суммы.
- **Заказы** — состав, контакты клиента, смена статуса (клиент получает уведомление), ответ клиенту.
- **Сообщения** — переписка с клиентами как в мессенджере, можно отвечать текстом и фото.
- **Заявки под заказ** — фото и описание от клиента, статусы, ответ.
- **Товары** — добавить с фото, изменить, скрыть, удалить.
- **Рассылка** — всем клиентам, с фото.

## Важно
- Панель доступна только на этом компьютере (127.0.0.1) и закрыта паролем.
- Для загрузки фото админ должен хотя бы раз нажать /start у бота.
- Фото с iPhone в формате HEIC: раскомментируй `pillow-heif` в requirements.txt и установи заново.
- Клиенты теперь могут просто писать боту обычным текстом — это попадает в «Сообщения».
